# 🖌️ StyleSync (Google slides improvements)

### Characteristics

**Study year**: 1st year of Master's  
**Course name**: Fundamentals of Situated Interaction  
**Language**: English  
**Team size**: 3  
**Programming language**: ∅

### Project Description

The goal of this project was to redesign a feature of Google Slides to enhance its usage. We chose to redesign the template feature of Google Slides and make it easier and faster to use by providing new interactions.
