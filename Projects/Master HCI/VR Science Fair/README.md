# 🧪 VR ScienceFair 

### Characteristics

**Study year**: 1st year of Master's  
**Course name**: The Art of Fabricating Tangible Surfaces  
**Language**: English  
**Team size**: 2  
**Programming language**: ∅  
**Software/Website**: Unity, Sketchfab, Sweet Home 3D  

### Project Description

The goal of this project was to create a VR game where the user is teleported into a science fair and can interact with experiments that use physics and sound.
